# TIDEBREAKER

A mobile-first HTML5 deep-sea exploration game using vanilla Canvas.

## Gameplay

Steer a small submarine downward through a drowned world.

- Drag/hold on mobile to steer.
- WASD / arrow keys on desktop.
- Avoid rocks.
- Recover wreckage for scrap.
- Fish and collisions damage oxygen.
- Oxygen decreases over time.
- Descend as far as possible.

## GitHub Pages

Upload `index.html`, `style.css`, and `game.js` to a GitHub repository. Enable GitHub Pages from the `main` branch. No build tools or dependencies are required.
